# Hounter - Advanced Landing Page

This project is part of the Advanced Landing Page module for the UI Internship program at Grid Dynamics.

## Run Locally

### Clone the project

```bash
git https://github.com/AgusGrid/hounter-altamirano.git
```

### Install dependencies

```bash
npm install
```

### Start local server

```bash
npm run dev
```

## Tech Stack

**Frontend:** HTML5, Vanilla JavaScript

**Styling:** Sass/SCSS

**Build Tools:** Sass Compiler

**Development Tools:** Live Server, Concurrently
